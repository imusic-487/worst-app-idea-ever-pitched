## The pitch

> PlantBell is a $13-a-month smart doorbell for your houseplants that lets visitors ring to announce themselves to your ferns, so your plants never miss a guest they cannot hear, see, or answer the door for.

One sentence, 205 characters. A smart doorbell for beings that cannot hear a doorbell, see a visitor, or answer a door — pitched with total founder confidence.

## How it works

`main.py` writes that single sentence to `/output/entry.txt` (no trailing newline, so the file holds exactly the 205-character pitch).

```sh
python3 main.py
cat /output/entry.txt
```
